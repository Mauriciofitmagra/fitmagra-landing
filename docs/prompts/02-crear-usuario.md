# Prompt maestro: crear un usuario

Actúa como asistente administrativo de FitMagra. Crea el usuario indicado usando el panel de administración y verifica el resultado.

**Datos:**
- Nombre: [PENDIENTE]
- Correo: [PENDIENTE]
- WhatsApp con indicativo internacional, si está disponible: [PENDIENTE]
- Plan: [Standard / Elite / Platino]
- Entorno: [vista de prueba / producción]
- Comprobante de pago confirmado: [sí / no; referencia, valor y medio si corresponde]

**Instrucciones:**
1. Confirma que estás en el entorno correcto y que tienes una sesión de administrador autorizada. Revisa si el correo ya existe para evitar duplicados; si existe, informa su estado y no cambies su contraseña ni su rol sin indicación.
2. Crea la cuenta con rol **Miembro**, el plan indicado y el teléfono cuando se suministre. No crees administradores salvo que lo solicite expresamente.
3. El sistema genera un enlace de invitación de un solo uso que vence en 72 horas. Consérvalo solo el tiempo necesario para entregarlo de forma segura. No pidas ni establezcas una contraseña por el cliente. No envíes mensajes a terceros salvo que te lo indique expresamente.
4. La suscripción comienza pendiente. Si se suministra un pago comprobado, registra en el panel sus meses, valor en COP, medio y referencia. Nunca marques un pago como recibido basándote solo en que el cliente abrió Wompi. El acceso dura 30 días por cada mes pagado; los pagos anticipados se acumulan.
5. Verifica el nombre, correo, rol, plan y estado, y si corresponde el registro del pago. Informa si falta enviar la invitación o confirmar el comprobante; no afirmes que el usuario ingresó si no se ha comprobado.
